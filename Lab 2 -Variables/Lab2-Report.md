### Notes – C Data Types & Format Specifiers

- `int` → `%d` : Used for integers (e.g., `22`).
- `float` / `double` → `%f` : Used for decimal numbers (e.g., `93.02`).
- `char` → `%c` : Used for single characters (e.g., `'S'`).
- `char[]` → `%s` : Used for strings (e.g., `"Samar"`).
- `%.2f` : Displays a floating-point number with two decimal places.
